About the Project

Messenger is a lightweight web-based messaging application designed to make communication between students, instructors, and team members faster and more organized. In many course or project environments, communication can become scattered across email, group chats, and announcements, which makes it harder for users to know where to send messages or how to find important updates. Messenger addresses this problem by providing one simple platform for public announcements, public chat, and private messaging. The target users for Messenger include students, course instructors, teaching assistants, and project team members. Students can use the application to ask questions, receive updates, and communicate privately with classmates or instructors. Instructors and teaching assistants can use Messenger to send class-wide announcements, answer questions, and check communication activity in a structured way. At a high level, Messenger will allow users to log in, view available chats, send and receive public messages, send and receive private messages, and check whether another user is currently online. The application will focus on core communication features first, including user authentication, public chat, private chat, and message display. Future improvements may include message history search, notifications, file attachments, and improved user roles. The system will follow a simple client-server architecture. Users interact with the Messenger web interface through a browser. The frontend sends requests to the backend server, which handles authentication, message processing, user status, and database operations. The database stores user accounts, public messages, private messages, and user session or online status information.
