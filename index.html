The Project

What is Chattr?

Chattr is a lightweight, real-time web-based messaging application designed to make communication between students, instructors, and team members faster and more organized. In many course or project environments, communication becomes scattered across email, group chats, and announcements. Chattr addresses this by providing one focused platform for public announcements, group chat, and private messaging.

Built with a Node.js and Socket.io stack, Chattr follows a client-server architecture where all real-time communication flows through a central server. The application is deployed to Azure App Services with automated CI/CD via GitHub Actions — every push to the sprint branch triggers a fresh deployment.

Security is treated as a cross-cutting concern throughout development (SSDLC): input validation runs on both client and server, all user-controlled output is sanitized with DOMPurify, and a strict Content-Security-Policy header is applied on every server response.
